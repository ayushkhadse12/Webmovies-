CATALOG AUTOMATION

Add a movie or web series

📖 How it works

  • Auto-fetch: Just enter the title — poster, description, rating, year, and episodes are automatically fetched from TMDb. You can override the poster with a custom URL.
  • TMDb ID: If the auto-search picks the wrong movie, enter the exact TMDb ID from themoviedb.org.
  • Movies: Select TeraBox or Direct URL as provider. For TeraBox, give the file path (e.g. /WebMovies/Movies/Inception.mp4). For multi-part, separate with commas.
  • Series: All seasons & episodes are auto-imported from TMDb. Attach video files via the Episode Media Map JSON.
  • Video sources: All videos can be hosted on TeraBox, Google Drive (direct link), or any cloud with a direct MP4 URL.

The selected file is uploaded to this WebMovies server and can then be streamed by users.

The series information and posters are automatic. You can attach TeraBox episode paths now or add them later.

COMING SOON

Add upcoming media

📖 How it works

  • Auto-fetch: Enter the title — poster and description are automatically fetched from TMDb. You can override the poster URL.
  • Hover preview video: Add a short trailer or clip URL. When users hover on the card, the video plays automatically. Use any direct MP4 link from TeraBox, cloud storage, etc.
  • Types: Choose "Movie" for upcoming movies, "New Series" for new series, or "New Season" for an existing series getting a new season.
  • Card size: You can change the size of Coming Soon cards in Settings.

HERO BANNER

Add custom hero poster

📖 How it works

  • Auto-fetch: Enter the movie/series title — poster (backdrop) and description are automatically fetched from TMDb.
  • Hover preview video: Add a trailer/clip URL. When users hover over the hero poster, the video plays as a preview. Use any direct MP4 link.
  • Position: Set 0 for first, 1 for second, etc. Leave blank for last. Reorder with ↑↓ buttons in Manage Catalog.
  • Big posters: These are the large full-width banners at the top of the homepage that auto-rotate in a slider.
